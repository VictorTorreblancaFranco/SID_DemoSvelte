# Kipo · Pali Wallet

Aplicación web desarrollada con Svelte que permite conectar Pali Wallet, consultar la dirección pública de la cuenta y mostrar el saldo de la red seleccionada.

## Funciones

- Conexión con Pali Wallet.
- Lectura de la dirección pública.
- Consulta y actualización del saldo.
- Detección de la red seleccionada.
- Copiado de la dirección.
- Desconexión de la billetera.

## Tecnologías

- Svelte 5
- TypeScript
- Ethers.js 6
- Vite

## Ejecutar el proyecto

```bash
npm install
npm run dev
```

Después, abrir la dirección local mostrada en la terminal y tener instalada la extensión Pali Wallet en el navegador.
